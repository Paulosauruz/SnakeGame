# Java Snake Game
### About
This is a quick recreation of the famous snake game that I made in Java. The objective is to learn about OOP, JFrame, game loop, and to practice my coding skill. 
The entire project development from start to finish span across two days during my free time. 
### Features
The game is very simple. 
- Use WASD or arrow keys to control the snake.
- If you touch the border or yourself, you lose. 
- Collecting food which spawns randomly around the map will give more lengths/score.
- Every 10 lengths increase, your speed increase by one, capped at 12.
- Scores and speed are displayed on the top right corner.
  
The game is not optimized in anyway. It is just a quick project to learn the overall framework of programming.
